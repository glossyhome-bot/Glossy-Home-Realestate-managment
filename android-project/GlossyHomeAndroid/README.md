# Glossy Home Real Estate – Android APK project

This Android Studio project wraps the live Glossy Home PWA at:
https://lingering-glade-fb92.glossyhome-uae.workers.dev/

## Build APK
1. Install Android Studio.
2. Open this folder as a project.
3. Let Gradle sync and install the requested Android SDK/Build Tools if prompted.
4. Build > Build APK(s).
5. The debug APK will be under app/build/outputs/apk/debug/.

The app opens the live PWA so Google Login and Google Drive sync use the same web app.
